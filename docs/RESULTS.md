## Caveat

The company, the money and the vendors are synthetic, generated by seed/generate.py with seed 42, and the planted errors come from the same generator that made the clean rows. Recall and precision therefore measure whether the kernel finds what we planted, not how it would behave on a real carrier's statements. Investigations in this run replay the recordings of the live Droid run of 2026-10-24 (six decoys re-recorded the same day), labelled replayed on every card; no live model ran during the measured run. The scripted controller (scripts/controller_sim.py) decides from the dispatcher's swap log in the evidence folder, which is what a human controller would consult; it never reads the answer key, but the swap log is produced by the same generator, so the decoy result shows the mechanism works, not that a human would judge the same way.
